## 📝 Descripción del Proyecto
El proyecto  llamado SistemaPedidos corresponde a la Actividad Obligatoria N°1.

La idea del ejercicio es analizar, ordenar e interpretar información multimedial que el cliente nos otorgó de manera dispersa y desordenada (correos, audios, fotos y notas) para sentar de manera sólida las bases conceptuales y de diseño del sistema.
