## 📝 Descripción del Proyecto
**SistemaPedidos** es una solución de software orientada a objetos diseñada de manera personalizada para el **Kiosco "Sabor"**. El diseño de este sistema se fundamenta en un análisis crítico y ordenamiento de materiales e información desestructurada provista directamente por el negocio (tales como correos de clientes, transcripciones de videoconferencias, audios de WhatsApp e hilos del canal de Slack).

El sistema busca estructurar los flujos de interacción del cliente, optimizar el procesamiento de comandas en la cocina y garantizar una gobernanza de datos escalable mediante la aplicación de principios sólidos de ingeniería de software y programación orientada a objetos (POO).

### 🎯 Objetivo del Entregable (Actividad Obligatoria N° 1)
Este repositorio representa el primer hito de entrega del proyecto, cuyo propósito es sentar de forma consistente las bases conceptuales, los diagramas lógicos y el control de calidad del ciclo de desarrollo colaborativo.
