## Descripción del Proyecto
Este repositorio contiene el desarrollo del **Sistema de Pedidos** para el Kiosco "Sabor-Kiosco" de Don Rubén. La aplicación busca resolver de manera profesional la gestión y organización del flujo de comandas y pedidos, interpretando de manera crítica los materiales dispersos provistos por el cliente (mails, audios de WhatsApp, fotos de comandas y transcripciones de reuniones de kick-off).

---

## Objetivo del Entregable
El objetivo de este primer entregable es sentar las bases conceptuales y de diseño orientado a objetos del sistema. Esto incluye:
* Identificación y especificación de Requisitos Funcionales (RF) y No Funcionales (RNF).
* Modelado detallado de 5 Casos de Uso del negocio.
* Diagramación del boceto de clases inicial a través de Excalidraw en VS Code.
* Configuración del entorno de trabajo colaborativo bajo la metodología GitFlow.
